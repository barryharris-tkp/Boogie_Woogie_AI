# Claude Code entry point

Read and follow [AGENTS.md](AGENTS.md) first, then [INSTALL.md](INSTALL.md). These are the shared instructions for Claude Code, Codex, and other installation agents.

Start with `python3 scripts/check-system.py --json`. Check hardware and existing services before large downloads. Use the pinned isolated runtime, keep services private, and verify actual local operation. The only optional cloud key is OpenAI artwork; the owner enters it directly in Studio settings. Never read a saved key or make a paid test request without authorization.
